# WriteMaster - AI 写作助手 ✍️

> 让每一次写作都恰到好处

## 功能特性

### 🎯 五大写作模式
- **✨ 润色**：让表达更流畅、更专业
- **🔄 改写**：换种说法，保持原意
- **📝 扩展**：增加细节和例子，让内容更丰富
- **✂️ 精简**：去掉冗余，保留核心信息
- **🌐 翻译**：支持 14 种语言互译

### 🎨 四种语气风格
- 💼 **专业**：正式、权威的商务语气
- 😊 **友好**：亲切、温暖的交流语气
- 🎯 **简洁**：直接、高效的表达方式
- 🎨 **创意**：有个性的创意表达

### 🌍 翻译支持语言
英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、泰语、越南语、印尼语、意大利语、中文

## 使用方法

1. **安装扩展**
   - 下载并安装 WriteMaster 扩展
   - 点击扩展图标，输入你的 DeepSeek API Key

2. **开始使用**
   - 在任何网页上点击文本输入框（textarea、input 或富文本编辑器）
   - 工具栏会自动出现在输入框上方
   - 选择功能按钮，AI 即刻为你优化文字

3. **应用结果**
   - 查看生成建议
   - 点击"应用"替换原文，或点击"取消"保留原文

## 技术架构

- **Manifest V3** - 符合 Chrome 最新标准
- **DeepSeek API** - 国内可直连的优质 AI 服务
- **Content Script** - 智能注入浮动工具栏，无缝融入各种网页
- **智能定位** - 自动适配输入框位置，不遮挡内容
